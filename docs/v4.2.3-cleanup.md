# v4.2.3 — repository cleanup

An audit of branches, workflows and code found redundancy that made the repository harder to maintain and the CI slower, without protecting more.

## Workflows

| Before | Now |
|---|---|
| A pull request that touched `tools/**` started up to seven jobs; the legacy gate ran three times, checkpoint 9 three times, and Playwright was installed three times. | Two jobs: `v4 PR quality` (the full `release` profile once, then the browser app regression and the PDF matrix) and `analyze` (PSScriptAnalyzer). |
| `v4 methodology`, `v4 report quality`, `v4 release gate` and the legacy `Report quality`. | Removed: each was a subset of the release profile (the release gate was only manual and repeated the `Release` workflow checks). |
| `v4 security regression` on every pull request and weekly. | Weekly only (and on demand); pull requests already run the same gates. |
| Two overlapping requirement files. | One `requirements-dev.txt`. |

## Code

- **Orphans:** scripts that no gate, workflow or document runs were removed with the checkpoint 1 folders only they used (`taxonomy/`, `schemas/`, `security-scenarios/`). `Test-ZeroTargetControls.py` failed when run and tested a guard replaced in v4.0.2. `Test-EvidenceAvailability.py` is a real negative test (evidence must come from package members, not declared sources), so it joined the gate instead.
- **Duplicates:** nine schemas were identical in checkpoint 4 and 5; checkpoint 4 now reads the checkpoint 5 copy and keeps the two schemas that differ (its fixture comes from an older collector).
- **Wrappers:** PowerShell wrappers around the Python entry points (root `arc-posture.ps1` and `Invoke-AssessmentPipeline.ps1`, the checkpoint gate wrappers, `tools/New-V4Report.ps1`) were removed together with their smoke test; the documented commands now call the Python entry points directly.
- **Dead code:** unused imports (ruff) and unused constants and attributes in the engines.
- **Gate:** `tools/Test-CodeQuality.py` runs ruff (pyflakes rules, `ruff.toml`) and fails on a script that nothing runs or mentions.

Collector logic and results did not change.
