Como as métricas são calculadas

Todas as métricas são calculadas neste navegador, só com os dados do pacote importado (results.json e pasta data). Nada é enviado nem estimado fora desses dados. O índice e o ganho são uma referência do kit para priorizar ações: não substituem o Secure Score nem a conformidade oficial do Defender for Cloud. Atenção: com amostra, cada máquina pesa muito no resultado; use o parque inteiro para a medida final.
