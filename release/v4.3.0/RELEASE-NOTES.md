## Changed

- **One calm look for the app and the v4 report:** flat navy header, pale surfaces, thin borders, tinted status colors with dark text instead of solid red, orange and violet, soft outcome bars, a proportional index ring, one table style (navy header, zebra rows) and numbered sections. Dark mode and print/PDF follow the same tokens.
- **v4 report:** each section carries a one-line purpose (EN-US and pt-BR); the executive summary and the action plan read as a presentation (KPI tiles, numbered actions).
- **App analysis:** the kit-index explanation and the two reading notes are folded; the Quick read no longer repeats the top gains already shown in "Do first"; the Executive assessment and the Evidence appendix are numbered parts.
- **Fix:** a stray `\1` next to the scope selector in "Prepare collection" (since v4.1.3) is removed.
- **Documentation and governance (EN-US and pt-BR):**
  - Portuguese twins of six documents that were English-only (methodology, threat model, query and evidence matrix, known issues, posture versus evidence, foundations of the claims); complete Portuguese `CONTRIBUTING.md`, `DISCLAIMER.md` and `SECURITY.md`. `tools/Test-DocParity.py`, part of the gate, keeps structure, URLs, code blocks and numbers aligned.
  - `THIRD-PARTY-NOTICES.md` (Feather Icons, MIT); the scope of `LICENSE-DOCS` is clarified and `CITATION.cff` points to both licenses, without changing any license.
  - `SECURITY.md` gains a fallback when private reporting is unavailable and an explicit rule against publishing credentials; the README says who the project is for and what it does not cover; `DISCLAIMER.md` and the README disclose the one local change the collector makes (the Azure CLI `resource-graph` extension).
  - Two documentation URLs that returned 404 are corrected, including the `officialSource` written into every package; outdated documents carry a historical banner; spelling reviewed (British spellings fixed in live files).
  - The approval text generated by `Prepare-Release.py approve` now states what was verified (checklist items verified by the release gates, recorded at the maintainer's request) and that it is not an independent audit.
  - Dependabot also watches `requirements-dev.txt`; repository settings were aligned (squash only, branch deleted on merge, security updates on, empty wiki and projects off).
  - Offline first: the README, `DISCLAIMER.md` and the app privacy notice recommend the offline copy of the app with real packages; the hosted page is only a convenience.
  - `tools/Test-Navigation.py`, part of the gate, exercises every wizard step, jump, menu link, filter and saved-analysis anchor (EN-US and pt-BR), plus every internal Markdown link.
