# Arc Posture Review v4.1.2 — single package patch candidate

**Status:** APPROVED_FOR_PUBLICATION — security review approved by Fabio Rodrigues Vieira Costa on 2026-11-06 (19/19). Tagging and publishing remain a separate, manual step.

## Fixed

- The README promised a v4 report generated by the collector (`-NoV4Report`) that had been removed in v4.1.0. The collector now does it: after the evidence is written it adds the canonical v4 report (Zero Trust × Tier, scenarios, action plan; EN-US and PT-BR) to the **same `.zip`** under `report/`. If Python 3.10+ or the kit download is unavailable, it warns and finishes with the evidence package; `-NoV4Report` skips the step.
- The engine and renderer come from the clone when the script runs inside one, otherwise from `arc-posture-kit.zip`, published with this release. The collector refuses the kit unless its SHA-256 equals the value pinned in the script.
- The app opens and saves the packaged report (*Open v4 report (Zero Trust)*, *Save v4 report (.html)*) and no longer flags `report/` as a file outside the manifest.
- README (EN-US/PT-BR), guide (Markdown and embedded HTML) and in-app notes describe the single-package flow: Collect, Open, Deliver.

## Preserved

- 64 checks (`CHK-01..CHK-64`) and 11 scenarios (`AS01..AS11`).
- Canonical `assessment-result.v4` contract version `4.0.0` and collector schema version 3.
- Read-only Azure access: the report step runs locally and calls no Azure API.

## Distribution status

This package contains no collected environment data or customer reports. The security review was approved on 2026-11-06. Tagging and publishing remain a separate, manual step; the release workflow re-verifies the manifest and `SHA256SUMS`, rebuilds the kit and uploads it with the script.
