# Security

**English** · [Português](#segurança)

If you find a vulnerability **in this repository** (for example in the generated script or the HTML), **do not open a public issue**. Use **Report a vulnerability** (private vulnerability reporting) in the repository *Security* tab. If that option is not available, open an issue that says only that you need a private channel for a security report, **without technical details, credentials, evidence or screenshots**, so the maintainer can arrange one.

Vulnerabilities in **Microsoft products or services** must be reported to the Microsoft Security Response Center: https://msrc.microsoft.com/create-report

Good practices:
- Never publish the evidence package (`.zip`) or excerpts with names, IDs or events from your environment.
- Never publish credentials, tokens or other secrets in an issue, a pull request or a report.
- Review the script before running it and use least-privilege accounts.

## Segurança

Se você encontrar uma vulnerabilidade **neste repositório** (por exemplo, no script gerado ou no HTML), **não abra uma issue pública**. Use **Report a vulnerability** (reporte privado de vulnerabilidades) na aba *Security* do repositório. Se essa opção não estiver disponível, abra uma issue dizendo apenas que você precisa de um canal privado para um reporte de segurança, **sem detalhes técnicos, credenciais, evidências nem capturas de tela**, para que o mantenedor providencie um.

Vulnerabilidades em **produtos ou serviços da Microsoft** devem ser reportadas ao Microsoft Security Response Center: https://msrc.microsoft.com/create-report

Boas práticas:
- Nunca publique o pacote de evidências (`.zip`) nem trechos com nomes, IDs ou eventos do seu ambiente.
- Nunca publique credenciais, tokens ou outros segredos em uma issue, em um pull request ou em um reporte.
- Revise o script antes de executar e use contas com menor privilégio.
