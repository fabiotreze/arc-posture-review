# Security

If you find a vulnerability **in this repository** (for example in the generated script or the HTML), **do not open a public issue**. Use **Report a vulnerability** (private vulnerability reporting) in the repository *Security* tab.

Vulnerabilities in **Microsoft products or services** must be reported to the Microsoft Security Response Center: https://msrc.microsoft.com/create-report

Good practices:
- Never publish the evidence package (`.zip`) or excerpts with names, IDs or events from your environment.
- Review the script before running it and use least-privilege accounts.
