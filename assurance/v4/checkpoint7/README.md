# Checkpoint 7 — Before/After and Verified Improvement

Checkpoint 7 adds the canonical before/after visual. It renders `comparison.controls` and `comparison.scenarios` without recalculating scores or change classification. A row already classified as `IMPROVED` by the Evaluation Engine is presented as **Verified Improvement**. When `comparison` is `null`, the Checkpoint 6 no-baseline disclosure remains the only comparison claim.
